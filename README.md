# FRAME/SHIFT 本地视频播放器

一个可以部署到 GitHub Pages 的静态网页。拖入本地视频，或在平板上点击选择文件，即可调速播放。视频通过浏览器的临时本地 URL 打开，不会上传到服务器。

功能：0.25× 到 4× 倍速、进度拖动、音量、静音、全屏、画中画（浏览器支持时）、键盘快捷键和更换视频。把鼠标移到播放器底部，或在平板上轻触底部，即可显示控制栏；离开底部 0.3 秒后自动隐藏。左右方向键每次跳 1 秒。

直接打开 `index.html` 即可使用。可播放格式取决于浏览器支持的视频编码。

## 在 iPad 上安装

用 Safari 打开网站，点击“分享”→“添加到主屏幕”，开启“作为网页 App 打开”，再点击“添加”。图标会出现在主屏幕。首次在线打开后，应用页面可以离线启动；视频仍从 iPad 的“文件”或照片中本地选择，不会被缓存或上传。
